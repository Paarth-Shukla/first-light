## Try it in a minute
1. On mobile, tap the voice mode icon (the sound wave symbol next to the microphone icon) in the text input field. On the web or Claude Desktop, start a new chat and tap the sound wave symbol in the lower right corner.
2. Choose a voice when prompted.
3. Start talking. In the default hands-free mode Claude responds when you finish a thought.
4. In a noisy place, switch to push-to-talk and hold the button while speaking.
5. On the web and desktop, click **Stop** to leave voice mode. The transcript stays in your chat history.

## Example
```text
Catch me up before standup. Check my calendar for today and summarize any email threads from the last day that mention the replication rollout. Then ask me three questions about what I got done yesterday and turn my answers into a short update I can read out.
```

## At work
- **Morning briefing.** With connected tools such as Gmail, Google Calendar, Google Docs and Slack, Claude can catch you up on email or check your calendar before a meeting by voice.
- **Rehearsal.** The docs list practicing for interviews or important conversations through natural dialogue.
- **Capturing ideas.** Talk an idea through, then switch to text in the same conversation to paste code or a URL.

## Pitfalls
- Voice mode is a beta feature and is built to work best from your phone.
- Voice conversations count toward your regular usage limits.
- Hands-free mode works best in quiet environments.
- Not every result can be shown on screen in voice mode, and using several tools at once can add a short delay.
- Claude Fable is not currently available in voice mode.
- In Claude Cowork and Claude Code, dictation is available but voice mode is not.
